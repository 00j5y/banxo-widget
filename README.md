# Banxo Widget

Application personnelle en SwiftUI et WidgetKit pour consulter le solde d'un compte Caisse d'Épargne sur iPhone et Mac. API privée conteneurisée pour un VPS.

## Développement

Le projet suit Gitflow : `main` pour les versions publiées, `develop` pour l'intégration, `feature/*` pour le développement, `release/*` et `hotfix/*` pour les livraisons et corrections.

Les identifiants bancaires ne sont jamais demandés par cette application. La connexion passe par Enable Banking et le parcours de la banque.

Voir [le plan de réalisation](docs/plan.md).
